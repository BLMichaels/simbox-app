Setup

  1. Download the app for your computer (Mac or Windows above).
  2. Download the Cases pack ZIP.
  3. Open SimBox and choose the Cases pack when prompted.
  4. Pick a case and run the simulation offline.

Installing on Mac

  1. Open the downloaded SimBox-mac.pkg.
  2. macOS will say it is from an unidentified developer, because SimBox is not registered with Apple. Right-click (or Control-click) the file and choose Open to continue.
  3. Follow the installer, entering your password when asked.
  4. Open SimBox from Applications — the installer already approved it, so there are no further warnings.

The installer needs your password because it installs into Applications and approves the app with macOS on your behalf.

First launch on Windows

  1. Run the downloaded installer.
  2. If SmartScreen appears, click More info → Run anyway.
