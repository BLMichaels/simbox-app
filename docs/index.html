Setup

  1. Download the app for your computer (Mac, Windows, or Chromebook above) and open it.
  2. Open SimBox. It starts on the case library.
  3. Click Download next to any case you want — Bronchiolitis, DKA, Scald Burn, and so on. Each one installs itself in about a minute.
  4. Click Open case and run the simulation. It works offline from then on.

You only download the cases you actually teach, and SimBox tells you when a case has been updated or a new one is published.

Using SimBox on a Chromebook

  1. Open SimBox for Chromebook in Chrome.
  2. Optional but recommended: open the Chrome menu (⋮) and choose Install SimBox / Save and open as window so it feels like an app.
  3. Click Download next to each case you teach. Wait until it says Installed.
  4. After that you can open those cases with no internet connection.

Installing on Mac

The first time only, macOS shows a security warning. That is normal for a small independent app like SimBox, and the steps below clear it in about a minute. You never have to do this again.

  1. Open the downloaded file

    Double-click SimBox-mac.pkg in your Downloads folder.

  2. Click “Done” on the warning

    macOS says “SimBox-mac.pkg” Not Opened. This is expected — click Done.

    Do not click “Move to Trash.” That deletes the installer.

  3. Open your Mac’s security settings

    This button opens the right settings page for you:

    Open Privacy & Security

    If your browser asks permission to open System Settings, choose Allow. If nothing happens, open System Settings from the Apple menu and click Privacy & Security in the sidebar.

  4. Click “Open Anyway”

    Scroll down to the Security heading. You will see a row like this:

    “SimBox-mac.pkg” was blocked to protect your Mac. Open Anyway

    Click Open Anyway, then type your Mac password to confirm.

    Don’t see that row? Go back to step 1 and double-click the file again — the button only appears just after macOS blocks it.

  5. Click through the installer

    The SimBox installer opens. Continue through it, entering your Mac password when asked.

  6. You’re finished

    Open SimBox from your Applications folder. No more warnings — the installer already approved the app for you.

    If macOS says the installer “is unable to be moved to the Trash,” ignore it and click OK. SimBox is already installed; that message is only about tidying up the downloaded file, and you can delete it yourself later.

Still blocked after all that?

Open the Terminal app, paste the line below, press Return, then double-click the installer again. This removes the download flag macOS put on the file.

xattr -d com.apple.quarantine ~/Downloads/SimBox-mac.pkg

If you would rather not do that, send the file back to us and we can install SimBox with you directly.

First launch on Windows

  1. Download SimBox-windows.exe and double-click it.
  2. If Windows shows a blue SmartScreen warning, click More info, then Run anyway.
  3. Click through the installer, then open SimBox from the Start menu or desktop shortcut.
  4. In the case library, click Download next to any case you want to teach.

Chromebooks should use the Chromebook option above, not the Windows installer.
