Setup

  1. Download the app for your computer (Mac or Windows above).
  2. Download the Cases pack ZIP.
  3. Open SimBox and choose the Cases pack when prompted.
  4. Pick a case and run the simulation offline.

First launch on Mac

SimBox is not registered with Apple yet, so macOS asks for your approval the first time only.

  1. Open the downloaded SimBox-mac.dmg and drag SimBox into Applications.
  2. Open SimBox from Applications. macOS will say it cannot verify the developer.
  3. Go to System Settings → Privacy & Security, scroll down, and click Open Anyway.
  4. Confirm with Touch ID or your password. SimBox opens normally from then on.

Prefer the terminal? Run xattr -dr com.apple.quarantine /Applications/SimBox.app and it will open with no prompt.

First launch on Windows

  1. Run the downloaded installer.
  2. If SmartScreen appears, click More info → Run anyway.
